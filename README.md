# Bellas Boutique Frontend

Frontend del proyecto Bellas Boutique desarrollado para el curso Diseño de la Interacción Humano-Computadora.

---

## Tecnologías

- React 19
- Vite
- Tailwind CSS 4
- React Router DOM
- Axios
- React Icons
- SweetAlert2
- ESLint
- Prettier

---

## Requisitos

Antes de ejecutar el proyecto debe tener instalado:

- Node.js 22 o superior
- npm

Verificar instalación:

```bash
node -v

npm -v
```

---

## Clonar el proyecto

```bash
git clone https://github.com/pedro7amm/ProyectoBellasBoutiqueGrupo8.git
```

Entrar al proyecto

```bash
cd ProyectoBellasBoutiqueGrupo8
```

---

## Instalar dependencias

```bash
npm install
```

---

## Ejecutar

```bash
npm run dev
```

Abrir

```
http://localhost:5173
```

---

## Compilar producción

```bash
npm run build
```

---

## Vista previa

```bash
npm run preview
```

## Convenciones

- Un componente por carpeta.
- Nombres de componentes en PascalCase.
- Funciones en camelCase.
- No modificar código de otros módulos sin comunicarlo.
- Cada funcionalidad debe desarrollarse en una rama propia.

---

## Flujo de trabajo Git

Crear una rama

```bash
git checkout -b feature/login
```

Subir cambios

```bash
git add .

git commit -m "ej: Cambio hecho"

git push origin branch
```

Crear un Pull Request hacia `develop`.
